## 🚀 Overview

**NyasaTech1** is a professional IT solutions, corporate support, and custom software engineering platform operating in Malawi. Built with a minimalist, high-performance **dark-mode aesthetic**, the platform features a glassmorphic sticky header, a responsive mobile drawer navigation, smart session caching loaders, and interactive service cards with unique visual previews.

Led by **designer212** and technical partner **Jimmy Kuloya**, NyasaTech1 bridges the gap between complex digital solutions and local operational needs across Malawi.

---

## ✨ Key Features & Architecture

* **Smart Session Caching Loader**: Implements an immersive 5-second splash on the user's first home visit in a session, drops to 2.5 seconds on repeat home visits, and instantly bypasses loading screens on inner pages using `sessionStorage`.
* **Standardized Glassmorphic Navigation**: Sticky header with glass blur effects, smooth scroll behaviors, and an animated hamburger menu drawer that locks background scrolling on screens under `750px`.
* **Fullscreen Hero Carousel**: Dynamic background image carousel featuring smooth crossfades, custom navigation dots, and a vertical social sidebar for WhatsApp, Facebook, and Email channels.
* **Expandable Services Grid**: 13 comprehensive core services with unique background imagery, descriptive preview overlays, and smooth accordions revealing detailed specifications and direct support request triggers.
* **Production Software Showcase**: Highlights real engineering achievements including:
  * 💼 **Enterprise Payroll Web App**
  * 📄 **Document Scanner Utility Tool**
  * 📊 **Primary School Results Grading App**
